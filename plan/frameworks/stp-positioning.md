# ポジショニング

## 目的

ターゲット市場における自社の独自の立ち位置を定義し、競合との差別化を図る。

## サブ要素

| サブ要素 ID | 内容 |
|---|---|
| `axes` | ポジショニングマップの 2 軸 |
| `players` | 自社・競合の配置 |
| `target_position` | 狙うべきポジション |
| `value_proposition` | ターゲットへの提供価値 |

## 上流（参照すべき）

| 入力 | 上流フレームワーク | 生データ種類 |
|---|---|---|
| ターゲットの購買決定要因 | ターゲティング、セグメンテーション | CUSTOMER_RESEARCH |
| 競合の現在ポジション | 5Forces 分析 | COMPETITOR_INFO |
| 自社の強み | VRIO 分析、整理軸分析 | （上流経由） |

## 下流（出力先）

| 下流フレームワーク | 何を渡すか |
|---|---|
| 戦略コンセプトシート | ポジション、提供価値 |
| ブランドメッセージ | 提供価値の一言表現 |
| 4P 全体 | ポジションと提供価値 |

## データスキーマ

```typescript
{
  axes: {
    x: {
      label: string;                // 例：「価格」
      lowEnd: string;               // 例：「安い」
      highEnd: string;              // 例：「高い」
      rationale: string;            // なぜこの軸か
    };
    y: {
      label: string;                // 例：「本格度」
      lowEnd: string;               // 例：「手軽」
      highEnd: string;              // 例：「本格的」
      rationale: string;
    };
  };
  players: Array<{
    id: string;
    name: string;                   // 「自社」or 競合名
    type: 'self' | 'competitor';
    x: number;                      // -1.0 ~ 1.0
    y: number;
    note: string;
    sourceCompetitorInfoId?: string; // COMPETITOR_INFO 生データへの参照
  }>;
  targetPosition: {
    x: number;
    y: number;
    label: string;                  // 例：「初心者でも本格自然体験」
    rationale: string;              // なぜこのポジションを狙うか
  };
  valueProposition: string;         // ターゲットへの提供価値
}
```

## UI パターン

**インタラクティブ視覚化型**

レイアウト：

```
【軸の設定】
X 軸: [価格 ▼]   低: 安い  高: 高い   理由：[テキスト]
Y 軸: [本格度 ▼] 低: 手軽  高: 本格   理由：[テキスト]
[軸候補を提案]ボタン → ターゲットの購買決定要因から候補表示

【ポジショニングマップ】
        高
         │
      ●A│
         │  ●自社（狙う位置）
─────────┼─────────  X 軸（価格）
         │
   ●B  ●C  ●D
         │
        低

[自社をドラッグして配置] [競合追加 +]

【提供価値】
[ターゲット] 20代女性アニメ好き
↓
[提供価値] 初心者でも本格的な大自然を低価格で楽しめる
```

機能：
- 軸候補は STP のターゲットの「ベネフィット」から自動生成
- 競合は COMPETITOR_INFO の RawData から候補表示
- ドラッグ&ドロップで配置調整
- 「相関性が低い 2 軸を選ぶ」というガイドラインをツールチップ表示

## Claude Code 連携の例

```
「ターゲットの購買決定要因から、ポジショニングマップに使える
 軸の候補ペアを 3 通り提案して」

「COMPETITOR_INFO の RawData を全部読んで、各競合の
 ポジショニングマップ上の位置を推定して」
```

## 注意

- 軸は「相関性が低い 2 つ」を選ぶ（例：価格 × 価格帯 はダメ）
- 顧客視点で意味のある軸（購買決定要因）を選ぶ
- 「狙うポジション」が現在空白なら、ブルー・オーシャンの可能性
