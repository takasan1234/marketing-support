# セグメンテーション

## 目的

市場に存在する顧客を、同じニーズ・性質を持つグループ（セグメント）に細分化する。

## サブ要素

セグメンテーションは「整理軸（変数）」を選んでセグメントを定義する作業。
固定的なサブ要素はなく、「採用する変数」と「セグメント」を動的に作る。

### 整理軸（変数）の種類

| 変数カテゴリ | 例 |
|---|---|
| 人口動態（デモグラフィック） | 年齢、性別、家族構成、所得、職業、教育 |
| 地理的（ジオグラフィック） | 地方、気候、地域特性 |
| 心理的（サイコグラフィック） | ライフスタイル、パーソナリティ、価値観 |
| 行動（ビヘイビアル） | ベネフィット、利用形態、来訪頻度、態度 |

## 上流（参照すべき）

| 入力 | 上流フレームワーク | 生データ種類 |
|---|---|---|
| 整理軸の選定 | クロスSWOT（戦略の方向性） | CUSTOMER_RESEARCH, SALES_DATA |
| 顧客特性データ | （なし） | CUSTOMER_RESEARCH, SNS_ANALYTICS, LOCATION_DATA |
| セグメント検証 | （なし） | SNS_ANALYTICS, SEARCH_TRENDS |

## 下流（出力先）

| 下流フレームワーク | 何を渡すか |
|---|---|
| ターゲティング | 全セグメント |
| ポジショニング | 採用するセグメントの特性 |
| カスタマージャーニー | セグメント別の行動・思考 |

## データスキーマ

```typescript
{
  axes: Array<{                     // 採用する整理軸
    id: string;
    category: 'demographic' | 'geographic' | 'psychographic' | 'behavioral';
    name: string;                   // 例：「年齢」「ライフスタイル」
    values: string[];               // 例：["20代", "30代", ...]
    rationale: string;              // なぜこの軸を採用するか
  }>;
  segments: Array<{                 // 生成されたセグメント
    id: string;
    name: string;                   // 例：「20代女性アニメ好き」
    axisValues: Record<string, string>; // axisId → value
    characteristics: string;        // セグメントの特徴
    estimatedSize: string;          // 規模感（ざっくり）
    sources: string[];              // RawData ID
  }>;
  rationale: string;                // セグメンテーション全体の方針
}
```

## UI パターン

**テーブル + 動的軸追加**

レイアウト：

```
【整理軸の選定】
┌──────────────┬──────────────┬─────────────────┐
│ カテゴリ      │ 軸名          │ 値               │
├──────────────┼──────────────┼─────────────────┤
│ 人口動態      │ 年齢          │ 10代,20代,30代,…│
│ 心理的        │ ライフスタイル│ アクティブ,…    │
└──────────────┴──────────────┴─────────────────┘
[+ 軸を追加]

【生成されたセグメント】
┌──────────────────────┬───────────┬───────┐
│ セグメント名           │ 特徴       │ 規模感 │
├──────────────────────┼───────────┼───────┤
│ 20代女性アニメ好き      │ ...        │ ~50万人│
│ 30代男性アクティブ      │ ...        │ ~100万人│
└──────────────────────┴───────────┴───────┘
[+ セグメント追加]
```

## Claude Code 連携の例

```
「このプロジェクトの顧客調査と SNS 分析データから、
 採用すべきセグメンテーション軸の候補を 3 つ提案して」
```

## 注意

- 整理軸は 2 軸〜3 軸の組み合わせが現実的
- セグメンテーションは反復的：施策実施後に「実際に反応した層」と比較して見直す
- 心理的変数（ライフスタイル等）は把握が難しいので、Claude Code に SNS データから推定させると有用
