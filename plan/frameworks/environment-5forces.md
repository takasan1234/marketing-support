# 5Forces 分析

## 目的

自社・自事業に直接的に影響を与えるミクロ外部環境（業界構造）を、5 つの競争要因から分析する。

## サブ要素

| サブ要素 ID | 名称 | 説明 |
|---|---|---|
| `rivalry` | 競合との競争 | 既存競合との競争の激しさ |
| `new_entrants` | 新規参入者の脅威 | 新しい競合の参入しやすさ |
| `substitutes` | 代替品の脅威 | 別の解決手段に置き換えられるリスク |
| `supplier_power` | 売り手の交渉力 | 仕入先・サプライヤーの力 |
| `buyer_power` | 買い手の交渉力 | 顧客の価格交渉力 |

## 上流（参照すべき）

| サブ要素 | 上流フレームワーク | 生データ種類 |
|---|---|---|
| 全サブ要素 | （なし） | COMPETITOR_INFO, INDUSTRY_REPORT, MARKET_STATS |

5Forces も依存グラフの出発点。

## 下流（出力先）

| 下流フレームワーク | 何を渡すか |
|---|---|
| SWOT 分析 | Opportunity, Threat の材料 |
| 3C+C 分析（Competitor） | 競合環境の状況 |

## データスキーマ

```typescript
{
  rivalry: {
    intensity: 'low' | 'medium' | 'high'; // 圧力の強さ
    items: Array<{
      text: string;
      sources: string[]; // RawData ID
    }>;
    informationSources: string[];
    summary: string;
  };
  new_entrants: { /* 同上 */ };
  substitutes: { /* 同上 */ };
  supplier_power: { /* 同上 */ };
  buyer_power: { /* 同上 */ };
  overallSummary: string;
}
```

## UI パターン

**2 列テーブル型**

PEST と同じ構造だが、追加で「圧力の強さ」を 3 段階で評価。

レイアウト案：

```
┌──────────────────┬─────────────────┬─────────────────┬───────┐
│ 要素              │ 情報ソース        │ 分析結果         │ 強さ   │
├──────────────────┼─────────────────┼─────────────────┼───────┤
│ 競合との競争       │ [メモ]           │ [リスト]         │ [強]   │
│ 新規参入者の脅威   │                  │                  │ [中]   │
│ 代替品の脅威       │                  │                  │ [弱]   │
│ 売り手の交渉力     │                  │                  │ [中]   │
│ 買い手の交渉力     │                  │                  │ [強]   │
└──────────────────┴─────────────────┴─────────────────┴───────┘
```

## Claude Code 連携の例

```
「このプロジェクトの 5Forces を、業界レポートと競合情報から下書きして」
→ Claude Code が DB の INDUSTRY_REPORT と COMPETITOR_INFO を読んで生成
```

## 注意

- 既存競合のリストアップは「ポジショニングマップ」で使うので、ここで整理した競合情報は使い回せる
- 「圧力の強さ」の判定基準を UI 上でツールチップ表示する
