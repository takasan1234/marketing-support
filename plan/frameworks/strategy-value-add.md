# 高付加価値化 7 方法論

## 目的

商品・サービスの価値と価格を引き上げるための、7 つの方法論を適用可否で評価・選定する。

## 7 つの方法論

| ID | 方法論 | 内容 | マス向け | 高付加価値向け |
|---|---|---|---|---|
| `1` | 認知価値の二面構築 | 機能的価値 × 情緒的価値で構成 | ✅ | – |
| `2` | 段階的価格調整 | 低めスタート→段階的に値上げ | ✅ | – |
| `3` | 外部評価活用 | 権威・褒賞を活用 | ✅ | – |
| `4` | ステークホルダー協力 | エリア全体で価値の一貫性 | ✅ | ✅ |
| `5` | パーソナル感 | カスタマイズ、特別対応 | ✅ | ✅ |
| `6` | 枯渇感・希少性 | 限定・チャネル絞込 | ✅ | ✅ |
| `7` | 顧客の選択（エクスクルーシブ） | 価値を共有できる顧客を選ぶ | ✅ | ✅ |

## 上流（参照すべき）

| 入力 | 上流フレームワーク |
|---|---|
| 商品特性 | Product 戦略 |
| ターゲット | ターゲティング |
| 価格戦略 | Price 戦略 |

## 下流（出力先）

| 下流フレームワーク | 何を渡すか |
|---|---|
| Price 戦略 | 高付加価値化方法論の採用結果 |
| Product 戦略 | コア・形態・付随機能の追加 |

## データスキーマ

```typescript
{
  approach: 'mass_market' | 'high_value' | 'both';
  methods: Array<{
    id: '1' | '2' | '3' | '4' | '5' | '6' | '7';
    name: string;
    adopted: 'yes' | 'no' | 'considering';
    implementation: string;         // 具体的な実装方法
    rationale: string;
    relatedRawData: string[];       // RawData ID
  }>;
  overallStrategy: string;
}
```

## 注意

- アプローチ（マス向け / 高付加価値）で適用可能な方法論が変わる
- 採用する方法論は Price 戦略に組み込む
- 「ステークホルダー協力」は B2B でも、「パーソナル感」「希少性」は B2C で特に有効
