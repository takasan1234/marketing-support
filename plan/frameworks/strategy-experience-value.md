# 経験価値マーケティング

## 目的

商品・サービスが顧客に提供する「経験価値」を 5 つの視点で評価・設計する（Bernd Schmitt 由来）。

## サブ要素（5 つの経験価値）

| サブ要素 ID | 名称 | 内容 |
|---|---|---|
| `sense` | SENSE（感覚的価値） | 五感に訴える要素 |
| `feel` | FEEL（情緒的価値） | 感情・愛着を呼び起こす要素 |
| `think` | THINK（創造的・認知的価値） | 知的好奇心、新たな発見 |
| `act` | ACT（ライフスタイル価値） | 行動・習慣に影響する要素 |
| `relate` | RELATE（帰属価値） | コミュニティ・社会への帰属 |

## 上流（参照すべき）

| サブ要素 | 上流フレームワーク | 生データ種類 |
|---|---|---|
| 全サブ要素 | ポジショニング、ターゲティング | CUSTOMER_RESEARCH, SNS_ANALYTICS |

## 下流（出力先）

| 下流フレームワーク | 何を渡すか |
|---|---|
| Product 戦略 | 経験要素の組み込み |
| Promotion 戦略 | 訴求すべき経験要素 |

## データスキーマ

```typescript
{
  sense: {
    status: 'covered' | 'partial' | 'missing' | 'na';
    elements: string[];             // 具体的な要素
    note: string;
    sources: string[];              // RawData ID
  };
  feel: { /* 同上 */ };
  think: { /* 同上 */ };
  act: { /* 同上 */ };
  relate: { /* 同上 */ };
  overallSummary: string;
  priorities: string[];            // 強化すべき価値の順位
}
```

## UI パターン

**チェックリスト型**

```
【経験価値の評価】

■ SENSE（感覚的価値）— 五感に訴える要素
状態: [● 充足 ○ 部分的 ○ 不足 ○ 該当なし]
具体要素:
 ・[テキスト]
 ・[テキスト]
メモ: [テキスト]
関連生データ: [リンク]

■ FEEL（情緒的価値）— 感情・愛着
状態: [○ ● ○ ○]
...

■ THINK（創造的・認知的価値）
...

■ ACT（ライフスタイル価値）
...

■ RELATE（帰属価値）
...

【充足率（参考）】 ●●●○○ 60%

【強化すべき順位】
1. RELATE
2. THINK
3. ...
```

機能：
- 5 つの価値それぞれをチェックリストで評価
- 充足率はプログレスバー表示（参考値）
- 強化すべき優先順位を設定
- Product 戦略への反映ボタン

## Claude Code 連携の例

```
「現在の Product 戦略を見て、経験価値の 5 観点それぞれが
 どの程度カバーされているか分析して」
```

## 注意

- 全ての経験価値を満たす必要はない
- ターゲットが何を重視するかで優先順位が変わる
- Z 世代・ミレニアル世代は特に RELATE を重視する傾向
