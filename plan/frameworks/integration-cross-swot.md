# クロス SWOT 分析

## 目的

SWOT で洗い出した 4 要素を掛け合わせ、戦略の方向性を 4 つのパターンで導出する。

## サブ要素

| サブ要素 ID | 名称 | 内容 |
|---|---|---|
| `so` | S × O 積極攻勢 | 強みと機会を活用して何ができるか |
| `st` | S × T 差別化戦略 | 強みを活かして脅威を乗り越える方法 |
| `wo` | W × O 弱点強化 | 機会を逃さないために弱みを克服する方法 |
| `wt` | W × T 防衛・撤退 | 弱みと脅威が重なったときの対処 |

## 上流（参照すべき）

| サブ要素 | 上流フレームワーク | 生データ種類 |
|---|---|---|
| 全サブ要素 | SWOT 分析 | （SWOT 経由のみ） |

## 下流（出力先）

| 下流フレームワーク | 何を渡すか |
|---|---|
| STP（セグメンテーション、ターゲティング、ポジショニング） | 戦略の方向性 |
| 戦略コンセプトシート | ビジョン、戦略の方向性 |

## データスキーマ

```typescript
{
  so: {
    strategies: Array<{
      text: string;                // 戦略案
      feasibility: 'low' | 'medium' | 'high';  // 実現性
      impact: 'low' | 'medium' | 'high';       // 実現効果
      adopted: boolean;            // 採用するか
      sourceItems: {               // 参照した SWOT の要素
        strengths: string[];       // SWOT.strength.items のインデックス
        opportunities: string[];   // SWOT.opportunity.items のインデックス
      };
    }>;
  };
  st: { /* 同上：strengths + threats */ };
  wo: { /* 同上：weaknesses + opportunities */ };
  wt: { /* 同上：weaknesses + threats */ };
  selectedStrategies: string[];    // 採用する戦略の path 配列
  overallSummary: string;
}
```

## UI パターン

**2×2 マトリックス型**

```
                 │ Opportunity（機会）       │ Threat（脅威）
─────────────────┼──────────────────────────┼─────────────────────
   Strength     │ S × O 積極攻勢            │ S × T 差別化戦略
                │ ┌─ 上部に SWOT.S と     ┐│ ┌─ 上部に SWOT.S と  ┐
                │ │  SWOT.O の項目表示    ││ │  SWOT.T の項目表示  │
                │ └─                       ┘│ └─                    ┘
                │ 戦略案：                   │ 戦略案：
                │ ・[案1] 実現性:中 効果:高 │ ・[案1]
                │ ・[案2]                   │ ・[案2]
─────────────────┼──────────────────────────┼─────────────────────
   Weakness     │ W × O 弱点強化           │ W × T 防衛・撤退
                │ ...                       │ ...
```

機能：
- 各セルの上部に SWOT の該当要素を読み取り専用で表示
- セル下部に戦略案を複数入力
- 各戦略案に「実現性」「実現効果」を 3 段階で評価
- 「採用」フラグで強調表示

## Claude Code 連携の例

```
「SWOT を見て、4 セルそれぞれに戦略案を 3-5 個ずつ生成して」
→ 各セルで SWOT の組み合わせから戦略アイデアを提案
```

## 注意

- 戦略案が多すぎると後の STP に絞り込めないので、「採用」フラグの選別が重要
- 実現性と実現効果のマトリクス（4 象限）も補助表示すると判断しやすい
- 採用された戦略は戦略コンセプトシートに自動引用
