# 4C / 7P（4P の検証・拡張）

## 目的

- **4C**：4P をマーケットイン視点（顧客視点）で検証する
- **7P**：サービス特化型ビジネス向けに 4P を 3 要素拡張する

## 4C の構造

| 4P | 対応する 4C | 検証ポイント |
|---|---|---|
| Product | Customer Value（顧客価値） | 顧客のニーズを捉えているか |
| Price | Customer Cost（顧客負担） | 顧客が払ってもよい金額か |
| Place | Convenience（利便性） | 見つけやすく、買いやすいか |
| Promotion | Communication（双方向） | 選んでもらえる伝え方か |

## 7P の構造（4P + 3 要素）

| 追加要素 | 内容 |
|---|---|
| People（スタッフ） | 接客の質 |
| Process（プロセス） | サービス提供の効率・体験 |
| Physical Evidence（装飾物） | サービス提供時の演出・物理的環境 |

## 上流（参照すべき）

| 部分 | 上流フレームワーク |
|---|---|
| 4C | Product/Price/Place/Promotion 各 4P |
| 7P 追加要素 | Product 戦略 |

## 下流（出力先）

| 下流フレームワーク | 何を渡すか |
|---|---|
| Product/Price/Place/Promotion | 修正点フィードバック |

## データスキーマ

{
  fourC: {
    customerValue: {
      checked: boolean;
      assessment: 'satisfied' | 'partial' | 'unsatisfied';
      note: string;
      improvements: string[];
    };
    customerCost: { /* 同上 */ };
    convenience: { /* 同上 */ };
    communication: { /* 同上 */ };
  };
  sevenP: {
    enabled: boolean;               // サービス業の場合は true
    people: {
      currentState: string;
      target: string;
      gap: string;
    };
    process: { /* 同上 */ };
    physicalEvidence: { /* 同上 */ };
  };
}
```

```

## 注意

- 4C は 4P 完成後の「最終チェック」として実施
- 7P は B2B・B2C 関係なく、サービス要素が強いビジネス全般で有用
- 「People」は B2B 営業組織でも適用可能
