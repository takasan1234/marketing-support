# 戦略コンセプトシート

## 目的

STP までで検討した内容を 1 枚に集約し、組織内・関係者と戦略共有するための「設計図」を作る。

## サブ要素

| サブ要素 ID | 名称 | 内容 |
|---|---|---|
| `vision` | ビジョン | 中長期に目指す姿 |
| `issues` | 環境分析で明らかとなった課題点 | SWOT の Weakness, Threat の重点 |
| `direction` | 戦略の方向性 | クロスSWOT で採用した戦略 |
| `target` | ターゲット | STP の Target |
| `target_needs` | ターゲットのニーズと悩み | セグメンテーション・ターゲティング由来 |
| `position` | ポジション / 提供価値 | ポジショニングと提供価値 |
| `brand_message` | ブランドメッセージ | 提供価値の一言表現 |

## 上流（参照すべき）

| サブ要素 | 上流フレームワーク |
|---|---|
| vision | （自由設定 + クロスSWOT 参考） |
| issues | 3C+C、SWOT |
| direction | クロスSWOT |
| target | ターゲティング |
| target_needs | セグメンテーション、ターゲティング |
| position | ポジショニング |
| brand_message | ポジショニング全体 |

## 下流（出力先）

| 下流フレームワーク | 何を渡すか |
|---|---|
| 4P 全体 | 全項目 |
| KGI/KSF/KPI | ビジョンが KGI に直結 |

## データスキーマ

```typescript
{
  vision: string;
  issues: string[];                 // 箇条書き
  direction: string[];              // 戦略の方向性
  target: {
    main: string;                   // 例：「20-30代アニメ・アート好き層」
    sub: string;                    // 例：「上記の高所得層」
  };
  targetNeeds: string[];            // ニーズと悩み
  position: string;                 // 提供価値
  brandMessage: string;             // 一言メッセージ
  inheritedFrom: {                  // 自動引用元の記録
    visionFrom?: string;            // FrameworkEntry.id
    issuesFrom?: string[];
    directionFrom?: string;
    targetFrom?: string;
    positionFrom?: string;
  };
}
```

## UI パターン

**コンセプトシート型**

1 枚もののシート。レイアウト：

```
┌──────────────────────────────────────────────┐
│ 【ビジョン】                                          │
│ [複数行入力]                                          │
├──────────────────────────────────────────────┤
│ 【ブランドメッセージ】                                │
│ [1行入力（大きな文字）]                               │
├──────────────────────────────────────────────┤
│ 【課題点】               │ 【戦略の方向性】           │
│ ・[箇条書き]             │ ・[箇条書き]              │
│ [自動引用 ↓ 3C+C, SWOT] │ [自動引用 ↓ クロスSWOT]   │
├──────────────────────────────────────────────┤
│ 【ターゲット】                                        │
│ メイン: [テキスト]                                    │
│ サブ:   [テキスト]                                    │
│ [自動引用 ↓ ターゲティング]                          │
├──────────────────────────────────────────────┤
│ 【ターゲットのニーズと悩み】                          │
│ ・[箇条書き]                                          │
├──────────────────────────────────────────────┤
│ 【ポジション / 提供価値】                             │
│ [複数行入力]                                          │
│ [自動引用 ↓ ポジショニング]                          │
└──────────────────────────────────────────────┘

[A4 印刷プレビュー] [PDF エクスポート]
```

機能：
- 各セクションに「自動引用」ボタン
- 上流が更新されると「最新版で引用し直す？」と通知
- 印刷・PDF エクスポート対応（関係者共有用）

## Claude Code 連携の例

```
「戦略コンセプトシートを、STP の最新結果から自動で組み立てて」
→ vision 以外を全て埋める
```

## 注意

- このシートが「組織内合意形成」の起点になる
- 自動引用と手動編集を併用
- ブランドメッセージは何度も推敲する（重要な短文）
