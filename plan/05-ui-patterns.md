# 05. UI パターン

## 概要

PDF のフレームワーク表・図を 7 つの UI パターンに分類し、それぞれ専用コンポーネントを作る。各フレームワークは 1 つの UI パターンを採用。

## 1. 2列テーブル型（情報ソース × 分析結果）

**使うフレームワーク：** PEST分析, 5Forces分析, 整理軸分析, 3C+C分析

### レイアウト
```
┌─────────────┬─────────────────┬─────────────────┐
│ サブ要素     │ 情報ソース        │ 分析結果（±）     │
├─────────────┼─────────────────┼─────────────────┤
│ Politics    │ ・新聞           │ ・X 規制施行(+)   │
│             │ ・政府白書        │ ・Y 撤廃(-)       │
├─────────────┼─────────────────┼─────────────────┤
│ Economy     │ ...              │ ...               │
└─────────────┴─────────────────┴─────────────────┘
```

### 機能
- 各セルは複数行の箇条書き入力
- 「分析結果」列は影響の正負（+/-/±）をプルダウンで選択
- 「情報ソース」セルから生データへのリンクをドロップで紐付け
- 右サイドパネル：「このフレームワークに必要な生データ種類」を表示

### コンポーネント
`TwoColumnTable.tsx`

## 2. 2×2 マトリックス型

**使うフレームワーク：** SWOT分析, クロスSWOT分析

### レイアウト
```
                 │ Opportunity        │ Threat
─────────────────┼────────────────────┼─────────────────
   Strength     │ S × O 積極攻勢      │ S × T 差別化
                │ ...                 │ ...
─────────────────┼────────────────────┼─────────────────
   Weakness     │ W × O 弱点強化      │ W × T 防衛/撤退
                │ ...                 │ ...
```

### 機能
- 4 つのセルそれぞれ複数行入力
- SWOT のとき：4 セルは独立
- クロスSWOT のとき：他フレームワーク（SWOT）からの値を表示しつつ、4 つの戦略案を入力
- セル間ドラッグで要素移動

### コンポーネント
`MatrixTwoByTwo.tsx`

## 3. インタラクティブ視覚化型

**使うフレームワーク：** ポジショニングマップ, 戦略キャンバス, VRIO 分析, カスタマージャーニー

### 3a. ポジショニングマップ
- 2 軸を選択（X 軸 / Y 軸の見出しを自由設定）
- 各点（自社・競合）をドラッグで配置
- 「狙うポジション」を強調表示
- 競合点は生データ（COMPETITOR_INFO）から候補生成

### 3b. 戦略キャンバス
- 横軸：競争要素（自由に追加可能）
- 縦軸：レベル（低～高）
- 自社・競合の折れ線をプロット
- 「4 つのアクション（取除く・減らす・増やす・付け加える）」を要素ごとに記入

### 3c. VRIO 分析（フローチャート型）
- 各観光資源・経営資源を行として追加
- Value / Rarity / Imitability / Organization を Yes/No で判定
- 結果（持続可能な競争優位 / 一次的競争優位 / 競争均衡 / 競争劣位）を自動判定

### 3d. カスタマージャーニー
- 認知前 → 検討前 → 検討中 → 購入前 → 購入後 → 推奨者 のステージを横並び
- 各ステージで「行動」「思考・感情」「タッチポイント」を入力
- AIDMA / AISAS と紐付け

### コンポーネント
`PositioningMap.tsx`, `StrategyCanvas.tsx`, `VRIOFlowchart.tsx`, `JourneyMap.tsx`

## 4. ツリー型

**使うフレームワーク：** KGI/KSF/KPI, Product 3層構造

### レイアウト
```
KGI: 売上 20% UP
├─ KSF: 既存顧客リピート向上
│   ├─ KPI: NPS 70 以上
│   └─ KPI: 月次解約率 < 2%
└─ KSF: 新規顧客獲得
    ├─ KPI: 月次新規 100 件
    └─ KPI: CAC 5 万円以下
```

### 機能
- ノード追加・削除・並び替え
- 各ノードに数値目標・期限を入力
- Product 3層は同心円バリエーション（中心：コア、外側：形態、最外：付随）

### コンポーネント
`TreeEditor.tsx`, `ConcentricCircles.tsx`

## 5. コンセプトシート型

**使うフレームワーク：** 戦略コンセプトシート

### レイアウト
1 枚の集約シート。複数セクションが固定配置：
- ビジョン
- 環境分析で明らかとなった課題点
- 戦略の方向性
- ターゲット
- ターゲットのニーズと悩み
- 地域のポジション / ターゲットへの提供価値
- ブランドメッセージ

### 機能
- 各セクションは複数行入力
- 上流フレームワーク（クロスSWOT、STP 各種）から「自動引用」ボタン
- A4 印刷プレビュー対応

### コンポーネント
`ConceptSheet.tsx`

## 6. チェックリスト型

**使うフレームワーク：** 経験価値マーケティング（SENSE/FEEL/THINK/ACT/RELATE）, 高付加価値化 7 方法論, 4 つのアクション

### レイアウト
```
□ SENSE：五感に訴えかける要素
   [自由記入]

□ FEEL：情緒的な要素
   [自由記入]

□ THINK：創造的・認知的価値
   [自由記入]
...
```

### 機能
- チェックボックス + 自由記入欄
- 「該当する」「該当しない」「未確認」の3 状態
- 全体の充足率をプログレスバー表示（参考値）

### コンポーネント
`Checklist.tsx`

## 7. 比較カタログ型

**使うフレームワーク：** 価格設定3手法, プロモーション・ミックス5種, 3メディア, 販路設計, CRM 7分析手法

### レイアウト
カードグリッド。各カードに：
- 名称
- 特徴
- メリット / デメリット
- 自社適用可否
- メモ

### 機能
- 並列比較レイアウト（マス向け / 高付加価値の 2 列など）
- 採用したカードを「採用」フラグで強調

### コンポーネント
`ComparisonCatalog.tsx`

## 共通コンポーネント

すべての画面で使う共通要素：

| コンポーネント | 役割 |
|---|---|
| `UpstreamPanel` | 「参照すべき上流分析・生データ」を右サイドに表示 |
| `DownstreamPanel` | 「この分析の出力先」を表示 |
| `DataReferenceLink` | 生データへのインラインリンク |
| `VersionBadge` | バージョン番号と最終更新日 |
| `FreshnessIndicator` | 鮮度（緑/黄/赤）バッジ |
| `ClaudeCodeHint` | Claude Code への依頼文サジェスト |
